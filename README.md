# Personal Finance Analysis

An end-to-end analysis of personal income and expenses (January 2026) using Excel, SQL Server and Tableau.

## Key Findings
- Total income: ₹60,000
- Total expenses: ₹22,000
- Total savings: ₹38,000 (63% saving rate)
- Housing is the biggest expense at ₹12,000, about 55% of spending
- Food (18%) and Lifestyle (11%) are the next largest categories

## Tools Used
- **Excel:** SUM and SUMIF formulas, tables, column and pie charts
- **SQL Server:** SUM, GROUP BY, WHERE, AVG and percentage-of-total queries
- **Tableau Public:** interactive dashboard with category and income charts

## Files
- `PERSONAL FINANCE DASHBOARD.xlsx`: Excel dashboard
- `FINANCE_QUERIES.SQL`: SQL queries
